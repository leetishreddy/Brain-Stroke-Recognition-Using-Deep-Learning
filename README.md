# Brain-Stroke-Recognition-Using-Deep-Learning
This system uses deep learning to detect brain strokes from CT scan images through automated image analysis. A Sequential Convolutional Neural Network (CNN) identifies stroke-related patterns, supporting faster and more consistent diagnosis while reducing reliance on manual interpretation in clinical and telemedicine settings.
